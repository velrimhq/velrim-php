# Velrim PHP SDK

Official PHP SDK for [Velrim](https://velrim.com) — schema-first document extraction. Send a document, get back typed, validated JSON with visual grounding and calibrated confidence scores.

> **Status: not yet released.** This package reserves the `velrim` vendor namespace ahead of the PHP launch. The Velrim API itself is in **open beta** today — get an API key at [velrim.com](https://velrim.com), or use the [TypeScript SDK](https://www.npmjs.com/package/@velrim/sdk) (npm) or [Python SDK](https://pypi.org/project/velrim/) (PyPI) now.

## Installation (once released)

```bash
composer require velrim/velrim
```
