# Velrim PHP SDK

Official PHP SDK for [Velrim](https://velrim.com) — schema-first document extraction. Send a document, get back typed, validated JSON with visual grounding and calibrated confidence scores.

> **Status: not yet released.** This package reserves the `velrim` vendor namespace ahead of launch. The API and SDKs are in active development — join the waitlist at [velrim.com](https://velrim.com).

## Installation (once released)

```bash
composer require velrim/velrim
```
